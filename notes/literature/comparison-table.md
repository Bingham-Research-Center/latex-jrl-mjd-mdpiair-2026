# Cross-study comparison table

Supporting analysis only; this file is excluded from the MDPI submission package.

The local critiques and synthesis collections were used as routes, not as evidence.

Underlying passages are identified after the table so the comparison can be rechecked without treating heterogeneous studies as a factorial experiment.

## Interpretation boundary

This table is a design comparison, not an effect-size comparison.

The rows change episode, grid, platform, inventory, chemistry, intervention, and verification design, so their effects cannot be ranked or added across studies.
